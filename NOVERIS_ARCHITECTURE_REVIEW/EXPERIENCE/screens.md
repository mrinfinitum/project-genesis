Screen Definitions are the highest-level semantic design assets.

They compose:

- Experience Bible
- Visual DNA
- Inspiration Boards
- Tokens
- Materials
- Motion
- Components
- Interaction Patterns

Screen Definitions are not React pages, HTML layouts, CSS, routes, rendering code, or gameplay runtime data.
