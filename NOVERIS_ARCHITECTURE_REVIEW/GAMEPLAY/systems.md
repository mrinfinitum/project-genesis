# Gameplay Systems

Canonical gameplay systems currently represented in Studio include:

- Action System
- Planet Development Framework
- Civilization Identity
- Civilization Progression
- Colonization and Settlement
- Resource Economy and Logistics
- Missions and Expeditions
- Dynamic Events
- Population Simulation
- Discovery System
- Universal Discovery Registry
- Galaxy Engine contracts
- Planet Opportunity Profiles

These systems publish deterministic contracts into the canonical runtime when applicable.
