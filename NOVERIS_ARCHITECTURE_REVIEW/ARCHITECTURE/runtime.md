# Runtime Architecture

Runtime contract:

- architectureVersion: 1.0.0
- runtimeVersion: game-runtime-v1
- contentVersion: 32
- validationStatus: Ready

The sanitized runtime exposes canonical gameplay data and compatibility metadata. It must not expose Studio-private notes, decision logs, local source paths, private keys, or draft-only design data.

Experience Design remains draft-only and is excluded from gameplay runtime exports.
