# Ownership

Studio owns:

- Canonical content
- Canonical IDs
- Runtime contracts
- Engine export contracts
- Architecture Workspace
- Experience Design libraries
- Asset Library metadata
- Verification rules

Game owns:

- Rendering
- React / client implementation
- Three.js / shaders / camera
- Platform-specific UI code
- Player state
- Local gameplay presentation

Experience Design owns semantic intent only. It does not own runtime gameplay behavior.
