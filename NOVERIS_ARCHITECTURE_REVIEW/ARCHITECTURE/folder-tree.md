# Folder Tree

Key source areas:

- `lib/architecture`: Architecture Workspace, ownership, versioning, health
- `lib/runtime`: canonical game runtime builder and validators
- `lib/export`: multi-engine export adapters
- `lib/experience-design`: Experience Bible, Visual DNA, tokens, materials, motion, components, patterns, screens
- `lib/actions`: canonical action system
- `lib/colonization`: colonization and settlement contracts
- `lib/economy`: economy and logistics framework
- `lib/events`: dynamic event framework
- `lib/missions`: mission and expedition framework
- `lib/population`: population simulation framework
- `components`: Studio workspaces and UI shells
- `scripts`: verification, audit, import, and export tooling
