# Civilization Operations Deck Source Masters

These folders are the private canonical PSD/PSB production locations for the Civilization Operations Deck.

- Keep live labels, timers, progress, costs, player state, and controls out of baked artwork.
- Use named layer groups that match the canonical production asset IDs.
- Author at 3840 x 2400 with the Operations Deck positioned by its canonical screen-region contract.
- Preserve transparency for sliced HUD assets.
- Do not publish PSD or PSB files directly to runtime exports.
- Missing masters remain `Source Master Pending`; Studio does not fabricate replacements.

Game-ready PNG slices, atlas metadata, and manifests are generated from approved masters through the Studio export pipeline.
