## Observations

- `lib/data.ts` selects Supabase when configured, otherwise uses bundled handoff data and local fallback rows.
- Resource resolution is centralized in `lib/resources/service.ts`; this is a strong canonical boundary.
- Discovery volumes are discrete local source JSON packages.
- Fields such as active/draft/deprecated/invalid cannot be truthfully derived for every heterogeneous JSON file, so they are marked unresolved in the machine-readable inventory.
