# DV-02 NOVERIS Experience Bible

Release: DV-02 v0.1  
Status: Draft

The NOVERIS Experience Bible is the living creative reference for Project Genesis Studio. It is a structured Studio workspace, not a single markdown document and not a game implementation surface.

## What It Owns

Studio owns the Bible structure, parts, chapters, creative principles, references, attachments, linked concepts, linked mood boards, linked screen definitions, review states, governance, and version history.

The Game owns React, CSS, Three.js, shaders, animation code, platform rendering, live player state, and screen behavior.

## Structure

DV-02 v0.1 seeds:

- Parts I-VII
- Chapters 1-65
- Stable chapter IDs and slugs
- Structured body sections
- Review state and canonical status
- Version history
- Attachment and relationship fields
- noveris.life reference framework

The seeded chapters are intentionally minimal. They establish the authoring framework without writing the full Bible.

## Approval

Review states:

- Draft
- In Review
- Approved
- Deprecated
- Archived

Only approved chapters are canonical creative guidance. Draft chapters are visible for authoring but cannot silently become implementation authority.

## Revising Approved Content

Changes to approved content should create a new draft version. Do not overwrite approved history. Approval creates a versioned history entry with author, timestamp, and change summary.

## Adding A Chapter

Add new chapters through the Experience Bible registry. Use stable IDs and do not derive canonical identity from display titles. Link the chapter to a part, preserve chapter ordering, and add review/version metadata.

## References And Assets

Bible chapters may reference Asset Library records, design references, website snapshots, PDFs, videos, concept art, motion references, and approved NOVERIS assets.

Do not duplicate binary asset storage. Do not expose private local paths.

## noveris.life

noveris.life is a brand benchmark and continuity reference. It is not a literal one-to-one game layout, and Studio should not scrape or invent website content.

## Prompt Usage

Implementation prompts should cite approved Bible chapters when making creative or presentation changes. Gameplay rules remain governed by gameplay systems.
